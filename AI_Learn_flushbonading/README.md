## 笔记格式

- 文件统一使用 UTF-8 编码，扩展名为 `.md`。
- 编号与固定小节标题保持一致，例如 `1.9 链表、环形缓冲区与简单数据结构.md`。
- 采用 Markdown 标题、表格、`c` 代码块、工程案例、错题和参考链接。
- 这是公开仓库：请勿上传公司未公开源码、密钥、客户资料等敏感内容。

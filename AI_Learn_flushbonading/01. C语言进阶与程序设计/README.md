## 推荐复习方式

1. 先看各篇的“必须掌握的知识重点”，闭卷画变量地址、内存、指针或数据流关系。
2. 需要补充知识时，再阅读“系统知识讲解与代码分析”中的相应小节，不要只记题目答案。
3. 做“复习自检（闭卷）”，完成后再打开下方“参考答案与解析”核对原因。
4. 对错误进行区分：计算笔误、术语不准、概念错误、工程风险判断错误。
5. 本章综合复习后，继续 02. 计算机与MCU底层原理；STM32/ESP32-S3 项目实验可并行推进。

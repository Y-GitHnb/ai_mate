# 2.3 Flash、RAM、存储器映射与寄存器操作

> 所属目录 02. 计算机与MCU底层原理  
> 平台 STM32F407、STM32CubeF4/CMSIS、GCC。Flash 地址范围以 1 MiB 型号为例。  
> 学习状态 2026-11-24 通过综合验收。BSRR 写入掩码和 ODR 读回值留待间隔复核。

## 一、工程上要解决的问题

看懂一个地址时，先确认它属于哪个硬件，再确认访问的宽度、方向和副作用。排查 GPIO 时，区分寄存器配置、输出锁存值和引脚实际电平。排查启动变量时，区分固件初值所在的地址和程序运行时使用的地址。

## 二、存储器映射与外设访问

| STM32F407 地址范围 | 硬件目标 | 示例 |
|---|---|---|
| `0x08000000–0x080FFFFF` | 内部 Flash | 机器指令、常量、加载镜像中的初值 |
| `0x20000000–0x2001BFFF` | SRAM1 | 运行变量、栈帧、缓冲区 |
| `0x2001C000–0x2001FFFF` | SRAM2 | 另一区域的运行数据 |
| `0x40020000–0x400203FF` | GPIOA 外设窗口 | GPIOA 的配置、数据和操作寄存器 |

这些地址共用 CPU 的地址空间。以读取 `GPIOA->IDR` 为例，CPU 发出对 `0x40020000 + 0x10 = 0x40020010` 的 32 位读请求。总线硬件根据范围把请求经 AHB1 送给 GPIOA，GPIOA 根据内部偏移 `0x10` 选中 `IDR`，再返回数字输入状态。写 `GPIOA->BSRR` 时，同一个外设根据偏移 `0x18` 识别这次写操作。外设寄存器的读写行为由外设电路实现。

GPIOA 复位时由硬件建立配置寄存器的默认状态。应用也可以从 Flash 取出 GPIO 初始化指令，执行时把配置写入 GPIOA。`IDR` 的输入位来自引脚采样。GPIO 配置写入、引脚采样和将 `.data` 初值复制到 SRAM 是三个不同的过程。

## 三、Flash 初值与 SRAM 运行值

在常规 GCC 链接布局下、有实际分配空间的全局对象通常如下。

| C 对象 | 常见段 | 启动前后的数据位置 |
|---|---|---|
| `uint32_t gain = 9u;` | `.data` | Flash 保存初值，启动代码将它复制到 SRAM |
| `uint32_t count;` | `.bss` | 启动代码清零 SRAM 中这一段空间 |
| `const uint32_t table[] = {3u, 6u};` | `.rodata` | 表内容通常留在 Flash，程序按需要读取 |

STM32F407 的 ST GCC 模板在进入 `main()` 前处理这些初始化。`_sidata` 是 `.data` 初值的 Flash 起点，`_sdata` 和 `_edata` 描述 SRAM 目标范围。启动代码用加载和存储指令逐字复制，再清零 `.bss`。

在 Map 文件中，`.data` 的加载地址（LMA）通常在 Flash，运行地址（VMA）通常在 SRAM。若 LMA 为 `0x08018000`，VMA 为 `0x20000200`，`&gain = 0x20000214`，那么 `gain` 的段内偏移为 `0x14`，Flash 初值地址是 `0x08018014`。执行 `gain = 21u;` 后，Flash 初值仍为 `9`，SRAM 运行值为 `21`。常规复位再次执行启动复制后，进入 `main()` 时运行值恢复为 `9`。

如果需要掉电保存运行中的参数，软件须显式写入持久化区域。STM32F407 内部 Flash 的编程操作可将位从 1 改为 0，恢复为 1 需要擦除相应扇区。校验固件镜像时，若需要覆盖初始化内容，应按镜像布局纳入 Flash 上的 `.data` 初值字节。运行中的 SRAM 变量可能已经被应用修改。

## 四、用 C 访问 MMIO

STM32 设备头文件用结构体成员表示寄存器。`GPIOA` 提供寄存器块的基地址，`GPIO_TypeDef` 给出成员布局，`GPIOA->IDR` 将两者合起来。计算绝对寄存器地址时，先对整数地址加**字节偏移**，再按目标类型访问。`uint32_t *` 的加一是 4 字节，和手册的字节偏移单位不同。

以下示例假定 GPIOA 时钟已使能，PA4 已配置为数字输入。

```c
#include <stdbool.h>
#include <stdint.h>
#include "stm32f4xx.h"

bool pa4_is_high(void)
{
    return (GPIOA->IDR & (1u << 4)) != 0u;
}
```

这里进行一次 32 位读，再用 `0x10` 检查第 4 位。位号是移位量，掩码是 `1u << 位号`。对于同一次采样，可以先读到 `uint32_t snapshot = GPIOA->IDR;`，然后多次分析该快照。轮询外部引脚变化时，在循环条件里重新读取 `GPIOA->IDR`。给 `snapshot` 加 `volatile` 会让程序重新读取快照对象，它里面仍是先前存入的值。设备头文件里的 `volatile` 用于寄存器访问，是否允许写入以硬件手册的访问类型为准。

## 五、按寄存器规则选择写法

| 寄存器 | 访问语义 | 适用操作 |
|---|---|---|
| `GPIOA->IDR` | 低 16 位为只读输入状态 | 读回后按位检查 |
| `GPIOA->MODER` | 普通读写，每个引脚占两位 | 保留其他字段时读出、修改、写回 |
| `GPIOA->BSRR` | 写操作掩码，低 16 位置位，高 16 位复位 | 直接写目标位，查看 `ODR` 确认锁存结果 |
| `EXTI->PR` | W1C，写 1 清除对应挂起位，写 0 保持 | 直接写要清除的位掩码 |

假定 GPIOA 时钟已使能、只有这一处代码修改 `MODER`。PA6 的模式字段在位 `[13:12]`，通用输出的编码是 `01`。

```c
const uint32_t shift = 2u * 6u;
const uint32_t mask = 3u << shift;
uint32_t moder = GPIOA->MODER;
GPIOA->MODER = (moder & ~mask) | (1u << shift);

GPIOA->BSRR = 1u << 6;
```

`BSRR` 写入 `0x40` 会置位 `ODR` 的第 6 位。若原 `ODR = 0x20`，第 5 位保持置位，新的锁存值是 `0x20 | 0x40 = 0x60`。`BSRR` 的写入值和 `ODR` 的读回值分别描述操作与状态。

假定 `EXTI->PR` 初始为 `0x28`，只想清第 3 位且期间没有新事件：

| 写法 | 实际总线写值 | 操作后读回 |
|---|---:|---:|
| `EXTI->PR = (1u << 3);` | `0x08` | `0x20` |
| `EXTI->PR \|= (1u << 3);` | `0x28` | `0x00` |

后者先读取 `0x28`，再执行按位或并写回。回写值里第 3 位和第 5 位都为 1，硬件因此清除两位。

## 六、工程排查：ODR 已置位，引脚仍为低

1. 检查 `RCC->AHB1ENR` 中的 GPIOA 时钟使能位，以及 `MODER` 中目标引脚的模式。普通输入模式下，`BSRR` 可以更新输出锁存，输出驱动仍由模式决定。
2. 读 `ODR` 目标位确认输出锁存值。若没有按预期变化，先确认访问了正确的 GPIO 端口与引脚，以及是否有其他代码随后更新它。
3. 读 `IDR` 或测量引脚实际电平。通用输出且 `OTYPER` 对应位为 1 时，是开漏输出。开漏写 1 会释放输出驱动，检查是否有上拉、上拉电源是否正常、线路是否被其他器件拉低。

## 七、个人易错点与复习自检

| 易错点 | 复核方法 |
|---|---|
| 把外设映射理解为映射进 Flash | 追踪地址译码。`0x40020010` 选中 GPIOA 的 `IDR` |
| 把位号当掩码，或把 `IDR` 写成 `DIR` | 先确认寄存器名称，然后用 `1u << n` 只选第 `n` 位 |
| 用一次快照轮询引脚 | 逐行数读取 `IDR` 的次数，确认重新读外设的位置 |
| 把 `BSRR` 写值当作 `ODR` 新值 | 写入动作只影响掩码指向的位，输出锁存值按原状态推导 |
| 混用 W1C 的总线写值与读回值 | 先算表达式实际写了什么，再按写 1 清除规则算读回 |

**复习题**

1. `.data` 的 LMA 为 `0x08012000`、VMA 为 `0x20001000`，`&gain = 0x2000100C`。初值在哪？运行中修改 `gain` 会写到哪？
2. 初始 `ODR = 0x08`，执行 `GPIOA->BSRR = (1u << 5);`。实际写值和 `ODR` 读回值各是多少？
3. `EXTI->PR` 初始为 `0x84`，无新事件。直接写 `0x04` 和用 `|= 0x04` 分别写入多少、读回多少？

**参考答案**

1. Flash 初值在 `0x0801200C`。修改写到运行地址 `0x2000100C`。
2. 向 `BSRR` 写 `0x20`，`ODR` 读回 `0x28`。
3. 直接写时总线值是 `0x04`，读回 `0x80`。读改写时总线值是 `0x84`，读回 `0x00`。
